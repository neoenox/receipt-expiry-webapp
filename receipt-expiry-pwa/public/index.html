設定・使い方

ホーム画面に追加（PWA）

  1. iOS Safari: 共有ボタン →「ホーム画面に追加」
  2. Android Chrome: メニュー →「ホーム画面に追加」または「アプリをインストール」

追加すると、アイコンから全画面で起動できます。保存済みの在庫はオフラインでも閲覧できます。

賞味期限の通知

有効にすると、最も近い賞味期限の「日付だけ」をサーバーに保存し、その日以降にプッシュ通知を送ります。食材名や数量は送信しません。

オフライン解析キュー

オフラインで撮影したレシートは、接続が戻ったら自動で解析します。APIキーは端末に保存しません。

消費・廃棄の記録

食材を削除する際に「食べた / 捨てた」を選ぶと、今月の件数がここに表示されます。

在庫のバックアップ

在庫データをJSONファイルに書き出せます。読み込み時はIDが同じ食材をファイルの内容で上書きし、それ以外の食材はそのまま残します。

Gemini API キーの取得方法

解析にはGemini APIキーが必要です。Googleアカウントがあれば無料で取得できます。

手順をみる（タップで開く）
  1. Googleアカウントで Google AI Studio を開く
  2. 初回は利用規約に同意する
  3. 「API Keys」→「Create API key（API キーを作成）」を押す
  4. 既存のGoogle Cloudプロジェクトを使う場合は、先に取り込んでから選択する
  5. 表示された AIza... の文字列をコピーし、下のBYOK欄に貼り付けて「保存」を押す

2026-05-28以降の新規キーはGemini API専用の認証キーです。古い「Unrestricted」キーは拒否されるため、「Restrict to Gemini API only」を設定するか新規作成してください。

利用量は Usage ページ で確認できます。上限に達すると解析が429エラーになります。

自分のGemini APIキーを使う（BYOK）

キーを登録すると共有の利用制限なしで解析できます。キーはこの端末の localStorage にのみ保存され、サーバーには保存されません。取得方法は上の「Gemini API キーの取得方法」を参照してください。
